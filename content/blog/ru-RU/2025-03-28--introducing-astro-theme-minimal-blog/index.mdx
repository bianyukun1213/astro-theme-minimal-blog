Добро пожаловать в **Astro Theme: Minimal Blog** — отличный вариант, чтобы начать делиться своими идеями. Тему легко настроить, и в ней есть все необходимое для блога.

Если вы раньше использовали [@lekoarts/gatsby-theme-minimal-blog](https://github.com/LekoArts/gatsby-themes/tree/main/themes/gatsby-theme-minimal-blog), то быстро освоитесь: это естественное развитие версии для Gatsby.

## Возможности

- Пишите статьи в формате MDX
- Стили на базе [Tailwind](https://tailwindcss.com/)
- Блоки кода на базе [Expressive Code](https://expressive-code.com/)
- Кастомный компонент asides
- Интерактивный live coding на [Sandpack](https://github.com/codesandbox/sandpack)
- RSS и Sitemap
- Переключение темы: светлая/темная/системная
- Теги для статей
- Поиск на [Pagefind](https://pagefind.app/)

## Быстрый старт

1. **Важно:** убедитесь, что установлен [pnpm](https://pnpm.io/installation)
1. Клонируйте репозиторий [astro-theme-minimal-blog](https://github.com/LekoArts/astro-theme-minimal-blog).
1. Установите зависимости.
    ```shell
    pnpm install
    ```
1. Запустите сервер разработки.
    ```shell
    pnpm dev
    ```
