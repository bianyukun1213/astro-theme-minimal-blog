В этой статье вы узнаете, как использовать asides (также известные как "admonitions"), встроенные в тему. Иногда их также называют "callouts". Они удобны для вывода дополнительной информации рядом с основным содержанием страницы.

По умолчанию в теме доступны четыре типа aside-блоков:

- Note
- Caution
- Tip
- Danger

В MDX-файлах их можно использовать так:

````mdx
:::note
Это текст внутри блока note.
:::

Можно также задать собственные заголовки:

:::caution[Осторожно!]
Это предупреждающее сообщение!
:::

:::tip
Вот чему меня научили 10 советов о B2B.

```ts
const hello = 'world'
```
:::

:::danger
Не заходите на LinkedIn.
:::
````
