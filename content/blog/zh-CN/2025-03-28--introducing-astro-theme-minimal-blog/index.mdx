欢迎使用 **Astro Theme: Minimal Blog**。如果你想开始分享自己的想法，这是一个很理想的选择。它易于上手，并且具备搭建博客所需的一切功能。

如果你以前用过 [@lekoarts/gatsby-theme-minimal-blog](https://github.com/LekoArts/gatsby-themes/tree/main/themes/gatsby-theme-minimal-blog)，那你会很快熟悉它，因为它可以看作 Gatsby 版本的自然演进。

## 功能特性

- 使用 MDX 编写博客文章
- 使用 [Tailwind](https://tailwindcss.com/) 进行样式设计
- 由 [Expressive Code](https://expressive-code.com/) 提供支持的代码块
- 自定义的旁注组件
- 由 [Sandpack](https://github.com/codesandbox/sandpack) 提供支持的在线代码演示
- RSS 与站点地图
- 浅色 / 深色 / 跟随系统 的颜色模式切换
- 为博客文章添加标签
- 使用 [Pagefind](https://pagefind.app/) 搜索

## 快速开始

1. **重要：** 请先确认已经安装 [pnpm](https://pnpm.io/installation)
1. 克隆 [astro-theme-minimal-blog](https://github.com/LekoArts/astro-theme-minimal-blog) 仓库。
1. 安装依赖。
    ```shell
    pnpm install
    ```
1. 运行开发服务器。
    ```shell
    pnpm dev
    ```
