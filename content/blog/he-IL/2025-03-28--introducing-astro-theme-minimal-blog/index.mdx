ברוכים הבאים אל **Astro Theme: Minimal Blog**, אפשרות מעולה להתחיל לשתף את הרעיונות שלכם. היא קלה להגדרה וכוללת את כל מה שצריך בשביל בלוג.

אם השתמשתם בעבר ב-[@lekoarts/gatsby-theme-minimal-blog](https://github.com/LekoArts/gatsby-themes/tree/main/themes/gatsby-theme-minimal-blog), תרגישו כאן בבית, כי זו התפתחות טבעית של גרסת Gatsby.

## תכונות

- כתיבת פוסטים ב-MDX
- עיצוב עם [Tailwind](https://tailwindcss.com/)
- בלוקי קוד המבוססים על [Expressive Code](https://expressive-code.com/)
- רכיב asides מותאם אישית
- קידוד חי עם [Sandpack](https://github.com/codesandbox/sandpack)
- RSS ומפת אתר
- מעבר בין מצב בהיר/כהה/מערכת
- הוספת תגיות לפוסטים
- חיפוש באמצעות [Pagefind](https://pagefind.app/)

## התחלה מהירה

1. **חשוב:** ודאו ש-[pnpm](https://pnpm.io/installation) מותקן
1. שכפלו את מאגר [astro-theme-minimal-blog](https://github.com/LekoArts/astro-theme-minimal-blog).
1. התקינו את התלויות.
    ```shell
    pnpm install
    ```
1. הפעילו את שרת הפיתוח.
    ```shell
    pnpm dev
    ```
